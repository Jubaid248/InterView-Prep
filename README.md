# InterView-Prep

An AI-assisted practice studio for job interviews, structured communication, and IELTS Speaking.

## Practice tracks

- **Mock Interview** — practice for a target role using resume-informed questions, with STAR-method feedback.
- **Communication Builder** — structure and improve responses with STAR, CAR, SEE, and PAR frameworks.
- **IELTS Speaking** — rehearse the three-part speaking format and receive speaking feedback.

## Tech stack

- Next.js 14, React 18, and TypeScript
- Tailwind CSS
- MongoDB, MediaPipe Tasks Vision, and PDF parsing dependencies

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Features that connect to external AI or database services may need project-specific environment variables in a local `.env.local` file. Keep credentials out of version control.
